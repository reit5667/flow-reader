# PRD: FlowReader — iOS e-book reader

**Версия:** 1.0  
**Дата:** 2026-06-28  
**Платформа:** iOS (iPhone), App Store  
**Референс:** Moon+ Reader (Android)

---

## 1. Обзор и цели

FlowReader — нативная iOS-читалка электронных книг, вдохновлённая Moon+ Reader и e-ink устройствами. Цель — закрыть нишу, которой нет в App Store: минималистичное, быстрое приложение без лишних анимаций, с надёжными жестами, бесконечным скроллом и прямым доступом к Flibusta через встроенный браузер.

**Ключевые отличия от существующих iOS-читалок:**
- Бесконечный вертикальный скролл без случайного перелистывания страниц
- Надёжное управление яркостью свайпом по краю экрана
- Встроенный браузер для загрузки книг с Flibusta → автоимпорт в библиотеку
- Нулевые анимации, чистый минималистичный UI
- Выделение текста с шарингом в Obsidian через Flowtaker-бот

---

## 2. Целевая аудитория

**Основной пользователь:** читатель, который:
- Пользовался Moon+ Reader на Android и перешёл на iPhone
- Читает русскоязычную литературу (FB2) и зарубежную (EPUB)
- Скачивает книги с Flibusta, Litres, других источников
- Ценит минимализм и скорость над богатством функций
- Ведёт заметки в Obsidian / использует personal knowledge management

## 3. Основные функции и функциональность

### 3.1 Импорт книг

**Share Sheet / Open In:**
- Получение файлов через стандартный iOS Share Sheet (`Open in FlowReader`)
- Поддержка форматов: EPUB, FB2
- При получении файла — автоматическое добавление в библиотеку с парсингом метаданных (название, автор, обложка из файла)

Acceptance criteria:
- Из Safari / Files / любого приложения можно выбрать "Поделиться → FlowReader"
- Файл появляется в библиотеке без дополнительных шагов
- Если метаданные пустые — показывается имя файла как заголовок

**Встроенный браузер (Flibusta):**
- WKWebView с минимальным UI (адресная строка + кнопка закрыть)
- При скачивании `.epub` или `.fb2` файла — перехват загрузки, автоимпорт в библиотеку
- Стартовая страница: `flibusta.is` (или актуальный зеркальный адрес)
- Доступен из сайдбара раздел "Интернет"

Acceptance criteria:
- Открывается браузер с flibusta.is
- При нажатии "Скачать EPUB" файл перехватывается и появляется в "Моей полке" без сохранения в Files
- Показывается toast-уведомление "Книга добавлена в библиотеку"

### 3.2 Библиотека

**Главный экран — сетка с обложками:**
- Grid layout: 3 колонки, обложки с соотношением 2:3
- Под каждой обложкой: название книги, прогресс чтения в %
- Прогресс-бар под обложкой (тонкая полоса)
- Долгий тап на книге → контекстное меню: Удалить, Сменить обложку, Информация

**Управление обложками:**
- Если обложка есть в файле — используется автоматически
- Если нет — placeholder + возможность найти обложку через поиск (Google Images / Yandex Images через WKWebView)
- Пользователь выбирает изображение → сохраняется локально как обложка книги

Acceptance criteria:
- Библиотека отображается сеткой 3×N
- У каждой книги виден прогресс
- Можно сменить обложку через долгий тап

**Левый сайдбар (свайп вправо или кнопка ≡):**

| Раздел | Содержимое |
|---|---|
| Последняя книга | Превью последней открытой книги, быстрый переход |
| Моя полка | Вся библиотека (= главный экран) |
| Интернет | Встроенный браузер (WKWebView) |
| Настройки | Глобальные настройки приложения |

### 3.3 Ридер

**Режим чтения — бесконечный вертикальный скролл:**
- Непрерывный скролл без разбивки на страницы (как лента)
- Нет переключения страниц при случайном превышении порога свайпа
- Позиция сохраняется автоматически при закрытии книги (по символьному offset)

Acceptance criteria:
- Скролл плавный, без "прыжков" и случайного перелистывания
- После закрытия и повторного открытия — книга открывается на том же месте
- Прогресс в % обновляется в реальном времени при скролле

**Жесты в ридере:**

| Жест | Действие |
|---|---|
| Тап по центру экрана | Показать/скрыть нижний шит управления |
| Свайп вверх по левому краю | Увеличить яркость |
| Свайп вниз по левому краю | Уменьшить яркость |
| Свайп вправо (от левого края) | Закрыть книгу, вернуться в библиотеку |

Acceptance criteria:
- Зона жеста яркости: левая 15% ширины экрана
- Яркость меняется плавно, без дёрганий, с визуальным индикатором (полупрозрачная иконка солнца + уровень)
- Swipe back не конфликтует с жестом яркости

**Нижний шит управления (по тапу):**

Шит появляется снизу, поверх текста (не сдвигает контент). Два блока:

*Блок прогресса:*
- Название книги + автор
- Прогресс-бар (интерактивный — можно перетащить)
- % прочитанного
- Кнопки: Оглавление, Закладки, Поделиться выделенным

*Блок настроек (раскрывается по нажатию "Настройки"):*
- Тема: 4 варианта (Белая / Сепия / Тёмная / Чёрная)
- Шрифт: список системных + встроенных шрифтов (минимум: SF Pro, Georgia, Menlo)
- Размер шрифта: слайдер или +/- кнопки (12–28pt)
- Межстрочный интервал: 3 варианта (компактный / нормальный / широкий)
- Поля: 3 варианта (узкие / средние / широкие)
- Ориентация: авто / портрет / альбом

Все настройки применяются мгновенно, без перезагрузки контента.

Acceptance criteria:
- Шит появляется без анимации (или мгновенный fade, не slide)
- Смена темы применяется немедленно
- Настройки сохраняются между сессиями

### 3.4 Закладки и выделение текста

**Закладки:**
- Тап на иконку закладки в нижнем шите → текущая позиция сохраняется
- Список закладок с превью текста и % позиции
- Тап на закладку → переход к позиции

**Выделение текста:**
- Стандартный iOS text selection (долгий тап → выделение)
- После выделения — кастомный popup: Копировать / Поделиться / Закладка
- "Поделиться" → стандартный iOS Share Sheet (Notes, Flowtaker-бот, Telegram, и т.д.)
- Выделенный текст передаётся как plain text с указанием книги и автора: `"[цитата]" — Автор, Название книги`

Acceptance criteria:
- Выделение работает корректно в EPUB и FB2
- Share Sheet открывается с предзаполненным текстом цитаты
- Flowtaker-бот (Telegram) доступен в Share Sheet как цель

### 3.5 Оглавление

- Список глав из метаданных файла (NCX для EPUB, разделы FB2)
- Текущая глава помечена (галочка или выделение)
- Тап на главу → переход с сохранением предыдущей позиции в стеке (можно вернуться)

## 4. Технический стек (рекомендации)

| Компонент | Решение | Обоснование |
|---|---|---|
| Язык | Swift | Native iOS, лучшая производительность |
| UI | SwiftUI + UIKit (гибрид) | SwiftUI для навигации/библиотеки, UIKit для кастомного ридера |
| EPUB рендеринг | SwiftEPUB / самописный WKWebView рендерер | EPUB — это HTML/CSS внутри, WKWebView даёт полный контроль |
| FB2 парсинг | Самописный XML-парсер → HTML конвертер | FB2 — XML, конвертируется в HTML для рендеринга |
| Хранение файлов | FileManager (локальный sandbox) | Книги хранятся как файлы в Documents/ |
| База данных | SwiftData / CoreData | Метаданные, прогресс, закладки |
| Встроенный браузер | WKWebView | Системный, надёжный, App Store compliant |
| Перехват загрузок | WKNavigationDelegate | `decidePolicyFor` action — перехват .epub/.fb2 |

**Архитектура:** MVVM + Coordinator для навигации

## 5. Концептуальная модель данных

```
Book
├── id: UUID
├── title: String
├── author: String
├── filePath: String          // путь к файлу в sandbox
├── coverImagePath: String?   // путь к обложке (локально)
├── format: Enum (epub, fb2)
├── addedAt: Date
├── lastOpenedAt: Date?
├── readingProgress: Float    // 0.0 – 1.0
├── currentOffset: Int        // символьный offset
└── bookmarks: [Bookmark]

Bookmark
├── id: UUID
├── bookId: UUID
├── offset: Int
├── previewText: String       // первые ~100 символов после позиции
└── createdAt: Date

ReaderSettings                // глобальные, одна запись
├── theme: Enum (white, sepia, dark, black)
├── fontName: String
├── fontSize: Float
├── lineSpacing: Enum (compact, normal, wide)
├── margins: Enum (narrow, medium, wide)
└── orientation: Enum (auto, portrait, landscape)
```

## 6. Принципы UI-дизайна

- **Нулевые анимации:** все переходы мгновенные или с минимальным fade (≤100ms). Никаких slide, bounce, spring анимаций
- **Минимализм:** в ридере нет ничего кроме текста. UI появляется только по запросу (тап)
- **Тёмная тема по умолчанию:** соответствует предпочтениям целевой аудитории
- **Типографика:** системный шрифт SF Pro как дефолт, поддержка кастомных шрифтов
- **Цветовая палитра тем:**
  - Белая: bg `#FFFFFF`, text `#1A1A1A`
  - Сепия: bg `#F5E6C8`, text `#3B2A1A`
  - Тёмная: bg `#1C1C1E`, text `#E5E5EA`
  - Чёрная: bg `#000000`, text `#FFFFFF`
- **Иконки:** SF Symbols, без кастомных иконок где можно обойтись системными

## 7. Соображения по безопасности

- Файлы книг хранятся в app sandbox, недоступны другим приложениям
- WKWebView браузер не имеет доступа к данным библиотеки (изолирован)
- Никакой аутентификации пользователя в v1 — данные локальные
- При перехвате загрузки — валидация MIME-типа и расширения файла перед импортом
- App Store review: WKWebView с доступом к внешним сайтам — стандартная практика, не нарушает Guidelines при отсутствии явного продвижения пиратства в UI

## 9. Потенциальные проблемы и решения

| Проблема | Решение |
|---|---|
| FB2 рендеринг сложных структур (сноски, таблицы) | Конвертация в упрощённый HTML, сноски как popup |
| Flibusta меняет домен / недоступна | Настройка стартового URL в Settings, пользователь может изменить |
| App Store reject за WKWebView с пиратским контентом | Нейтральный UI браузера (просто "Браузер"), без упоминания Flibusta в App Store описании |
| Производительность скролла больших книг | Виртуализация контента: рендерим только видимые + буфер ±2 экрана |
| Перехват загрузок в WKWebView (некоторые сайты) | WKNavigationDelegate + URLSession fallback для прямых ссылок |

## 10. Будущие расширения (вне scope v1)

- **iCloud sync** — прогресс, закладки, библиотека синхронизируются между iPhone / iPad / Mac
- **Obsidian интеграция** — хайлайты и закладки экспортируются напрямую в Obsidian vault (через Flowtaker или прямой vault access)
- **Поиск по тексту** — полнотекстовый поиск внутри книги
- **Статистика чтения** — страниц в день, время сессии, прогресс по книгам
- **Дополнительные форматы** — PDF (без reflow), TXT, HTML
- **iPad / Mac версия** — через iCloud sync и Catalyst или отдельное приложение
- **Коллекции / полки** — группировка книг по тегам или пользовательским полкам
